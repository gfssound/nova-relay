Nova Relay Box

A Raspberry Pi on the cart that runs Nova Relay by itself: no laptop, no app to install on phones.

1 · Make the card image (on your Mac, about 10 minutes, once per version)

  1. Unzip Nova-Relay-<version>-Pi.zip. To change the box's Wi-Fi name, password or country, its name or its login, open Pi box settings.txt in TextEdit first and save it.
  2. Double-click Build Pi Image.command (the first time: right-click › Open › Open). It downloads Raspberry Pi OS Lite (64-bit, about 500 MB) and Node.js for the Pi, checks both against their published checksums, and makes Nova-Relay-<version>-Pi.img.gz next to it. The downloads are kept in a downloads folder for the next build.

On a Linux PC instead: sudo apt install mtools, then run ./"Build Pi Image.command" in a terminal.

2 · Write the card (about 5 minutes)

  1. Install Raspberry Pi Imager from raspberrypi.com/software and open it.
  2. Choose Device: your Pi. Choose OS › Use custom › the .img.gz file. Choose Storage: the microSD card.
  3. When Imager asks whether to apply OS customisation settings, choose No: they would replace the box's own setup.

One image makes as many cards as you like. balenaEtcher works too.

3 · First power-up (about 3 minutes, no internet needed)

Put the card in the Pi, plug the Aria into any USB port and power the Pi on. It sets itself up from the card: Nova Relay, its Wi-Fi network and its name. Then NOVA-REMOTE appears.

If NOVA-REMOTE hasn't appeared after 5 minutes, power the Pi off and put the card in your Mac: bootfs › nova-remote › setup-log.txt says what happened.

4 · On the cart

  1. Plug the Aria into any USB port on the Pi and power the Pi from the cart.
  2. On a phone or iPad, join Wi-Fi NOVA-REMOTE (password novaremote unless you changed it).
  3. Open http://nova.local (or http://10.42.0.1). Nova Relay finds the Aria by itself.
  4. Make it an app: in Safari tap Share › Add to Home Screen; on Android Chrome, menu › Add to Home screen. It then opens full-screen with its own icon.

Stream Deck

Plug it straight into one of the box's USB ports: its keys work like the Stream Deck plugin's, with no Stream Deck app. Choose what each key does in Setup › Stream Deck. (A box set up before 0.6.3 needs the installer run again, below, or a new card.) A Stream Deck on a Mac or PC can use the plugin instead, with the address nova.local:80.

Updating

Keeping its settings: join NOVA-REMOTE with your Mac, copy the new Pi zip to the box and run the installer: scp Nova-Relay-<version>-Pi.zip pi@nova.local:~, then ssh pi@nova.local, unzip it, cd into it and run sudo ./install-pi.sh. Or write a new card from the new image, which starts the box fresh.

Good to know

  • Power cuts: the Pi tolerates being switched off with the cart, but like any computer it's safest to unplug it a few seconds after the cart's last change. Settings save within a second of each change.
  • Range: the Pi's built-in Wi-Fi covers the cart and nearby. For more range, set HOTSPOT=no in Pi box settings.txt and join a proper travel router or cart access point.
  • No internet needed once it's set up. Phones on NOVA-REMOTE won't have internet unless the Pi has an Ethernet uplink.
  • Login: ssh pi@nova.local, password novaremote (set in Pi box settings.txt). Change it with passwd.
  • Logs: journalctl -u nova-remote -f on the Pi shows what Nova Relay is doing.
  • Without the Aria: once the direct Nova link is confirmed, the same box plugs into the Nova instead.
